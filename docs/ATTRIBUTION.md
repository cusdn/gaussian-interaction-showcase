# Attribution, provenance and release scope

## Included presentation assets

The static page, presentation styling, architecture diagram, aggregate results chart, procedural fixture screenshots and re-rendered reference video were produced for this showcase. The reference fixture uses original elementary geometry, procedural colors and a checker floor, with no captured image texture, external model or learned asset. The video replays an already completed MuJoCo trajectory. It is labeled synthetic throughout.

The MIT license in this package applies only to the original showcase presentation implementation, text and authored assets. It does not grant rights to upstream works, datasets, engines, or the private research implementation. Rights in underlying factual observations remain with their respective holders where applicable.

## Sources

- **Gaussian representation.** Kerbl et al., *3D Gaussian Splatting for Real-Time Radiance Field Rendering*, SIGGRAPH 2023. [Official project](https://repo-sam.inria.fr/fungraph/3d-gaussian-splatting/). The representation is an established foundation, not an invention claimed here.
- **MuJoCo.** [Official project](https://mujoco.org/) and [source / license](https://github.com/google-deepmind/mujoco/blob/main/LICENSE). Used to generate completed synthetic contact dynamics. No MuJoCo binary or source is packaged.
- **Real pushing measurements.** Yu et al., *More than a Million Ways to Be Pushed: A High-Fidelity Experimental Dataset of Planar Pushing*, IROS 2016. [MIT project and data](https://web.mit.edu/mcube/push-dataset/index.html). Original chart of project-computed aggregate facts only. No raw records, original figures or photos are redistributed, and no dataset relicensing is claimed.
- **Bonsai reconstruction evidence.** [Mip-NeRF 360 project](https://jonbarron.info/mipnerf360/) and [dylanebert/3dgs](https://huggingface.co/datasets/dylanebert/3dgs). A supplied public reconstruction was used in the original integration study. This package contains selected factual descriptions, not weights, input photographs or derived scene media.
- **Duck capture evidence.** [Gaussian Grouping data documentation](https://github.com/lkeab/gaussian-grouping/blob/main/docs/dataset.md) and [LERF](https://www.lerf.io/). Derived media, photographs, masks and fitted assets are excluded. Software license labels alone do not resolve original capture rights.
- **Unreal Engine.** [Official engine](https://www.unrealengine.com/). An integration target in the private project. No engine runtime, source, Starter Content, UE capture or vendor asset is packaged here.

## Excluded material

Unresolved source-image rights keep Bonsai and duck screenshots / videos outside this public package. Private algorithms, source files, model weights, training recipes, material hypotheses, experiment trajectories, raw data, unpublished method details, remote connection settings, credentials, enterprise material and original Git history are excluded.

Descriptive aggregate findings are release candidates awaiting the owner's publication approval, not peer-reviewed claims. Public availability of a source is not treated as permission to redistribute it. No university, laboratory, engine vendor or dataset author endorsement is implied.
